# Support

Revoot is pre-1.0. Only the latest release is supported, and behavior may change
between minor versions. The Rust crates are internal implementation details;
the CLI and documented CI integrations are the public surfaces.

Supported distributable targets are:

- `x86_64-unknown-linux-musl`
- `aarch64-unknown-linux-musl`
- `aarch64-apple-darwin`

GitHub.com and GitLab.com are the primary CI targets. Enterprise and
self-managed variants are best effort. Revoot currently supports Anthropic
Messages and OpenAI-compatible Responses APIs.
